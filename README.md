# Agent skills

General skills for AI agents.

## Skills

- **grill-with-reading** — prepare a design grill by tracing sources, teaching core ideas, and checking understanding.
- **lizard-complexity** — measure code complexity, simplify safely, and repeat until targets pass or no safe change remains.
- **explain-concept** — teach a concept with a visual, project examples, and a quiz.
